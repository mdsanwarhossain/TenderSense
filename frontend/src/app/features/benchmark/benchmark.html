How this is measured

  1. Take the {{ r.heldOutCount }} held-out tenders, of which {{ relevantCount() }} are labelled relevant.
  2. Rank that same pool with each matcher, using scores stored before this page loaded.
  3. Count how many of each system's top {{ r.k }} are actually relevant.

The keyword baseline is a real implementation, not a strawman — beating a crippled opponent would demonstrate nothing. What it structurally cannot do is match a tender that describes our work in words we do not use.
